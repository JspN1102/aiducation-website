# Spring Rain word-catching game assets

Created on 2026-09-19 for AIDUCATION's Ma On Shan Mandarin learning platform.

- `spring-scene.webp`: original background generated with `gpt-image-2` (high quality), resized to 1200 × 800 and encoded as WebP. 153,378 bytes.
- `leaf-boat.webp`: original Image2 leaf-boat reference converted into a detailed Tripo v3.1 PBR model, rendered offline and exported with real alpha transparency. 640 × 268, 42,798 bytes. Model version: `v3.1-20260211`.

These are generated project assets; this record does not grant an open-source licence. Original prompts, Image2 PNGs, the Tripo GLB, render evidence and checksums are retained in the local project backup.

The browser loads only the two WebP files (about 192 KiB combined). The 3D model is not downloaded during play, and the game requires no WebGL renderer.

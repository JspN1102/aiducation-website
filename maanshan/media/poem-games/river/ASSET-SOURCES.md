# Spring river local paint layers

All three `*-waiting.webp` files derive from `media/exploration/bo-chuan-gua-zhou/scene.webp`, an existing user-project illustration. No external image source was added.

Manually reviewed polygon zones select upper-left willow foliage (`willow`), near-bank grasses (`near`), and opposite-bank trees (`far`). Green/yellow-green pigment selection inside each zone creates a true-alpha overlay with muted pigment; feathered boundaries preserve the scene. The game erases these overlays locally under each brush dab to reveal the original painting. Water, sky, the boat and the moon are never recolored by the brush.

Scene credit and original source provenance remain with the existing exploration asset. The moored boat remains at Guazhou throughout the activity; the ending expresses longing for home, not a literal return journey.

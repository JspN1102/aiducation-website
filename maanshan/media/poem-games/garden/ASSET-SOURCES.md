# Garden bed

`garden-bed.webp` derives from the existing user-project asset `media/exploration/gui-yuan-tian-ju/scene.webp` (distant mountain, moon, field boundary), with a deterministic textured foreground soil continuation for individually interactive plants. It is not a newly licensed external image.

The game reuses the existing true-alpha `media/living-scenes/bean-v1.webp` and `grass-v1.webp`; their original source record remains in `media/living-scenes/ASSET-SOURCES.md`. No 3D engine is loaded.

This is a tending illustration inspired by the poem. Clearing eight foreground weeds is a player action, not a claim that the poem's field had few weeds; completion explicitly preserves 草盛豆苗稀.

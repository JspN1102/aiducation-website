# 教師下載：只需兩個按鈕

登入 https://mandarin.aiducation.asia/maanshan/teacher.html ，依次選好年級、古詩，再選班別；需要時調整日期。圖表和學生紀錄會一起更新，下載按鈕在下方。

**下載學生數據表格**：只有「學生明細」一張工作表，每位學生一行。八個欄目為年級、班別、座號、姓名、朗讀得分、聽音辨字、聽寫、練一練完成情況。空白是未測，0 分是實際評測結果。沒有跟進提示、內部遊戲分類分數或研究代號。

**AI生成教研報告**：由 AIDUCATION公司自研發AI Agent 撰寫學習分析與教學建議，完成後自動下載可編輯的 .docx。以連貫段落呈現整體評價、主要發現、問題分析和適合本年級的教學安排；按實際存在的學生分組提出建議。毋須輸入問題、另按分析、選模板或填寫教案表格。

同樣的資料再次下載會取回已保存的報告；有新的學習紀錄或範圍改變時會重新整理。生成期間請留在頁面；若停止等候，稍後按同一按鈕即可重試。切換範圍或登出會停止目前頁面的下載。

如果所選範圍尚無學習紀錄，Excel 仍可下載名冊；Word 會提示資料不足，不會編造學生表現。日期最多選 31 天。檔名包含班別及日期，方便保存。

報告和 Excel 只供已登入的教師下載。報告根據當時資料撰寫，教學建議供結合課堂觀察採用；未見紀錄不等於沒有學習，分數變化亦不能單憑本報告當作教學成效證明。

## 試用模擬後台

教師登入後，可開啟 https://mandarin.aiducation.asia/maanshan/teacher-demo.html 。模擬學習紀錄依學校名冊產生，操作與正式後台一致：先選年級及古詩，再選班別，查看班級圖表和簡要學生詳情，並以相同兩個按鈕下載表格或教研報告。模擬成績不代表真實學生表現。

模擬頁面、下載檔名和檔案內容都標有「模擬數據」。模擬資料不會匯入真實學生紀錄或研究資料庫，生成的模擬報告亦與正式報告分開保存。按「返回正式後台」即可查看學校的真實資料。

## 伺服器保存

學校網頁保留原網址。帳戶、學習紀錄及新產生的正式／模擬報告由廣州 PostgreSQL 保存；Vercel 僅透過固定目的地的加密 SSH 通道轉送 API，不再依賴免費 Blob 額度。正式報告與模擬報告以獨立資料鍵分開；資料庫每日完整備份。

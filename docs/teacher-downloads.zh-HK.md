# 教師下載：只需兩個按鈕

登入 https://mandarin.aiducation.asia/maanshan/teacher.html ，選好年級、班別；需要時調整日期。直接按以下其中一個按鈕，毋須再按套用。

**匯出 Excel**：下載所選範圍的學生紀錄。先看「學生明細」：每位學生一行，列出紀錄、分項評測及跟進提示；「概覽」「分項表現」「每日趨勢」「字音重點」「說明」提供詳細資料。空白是未測，0 分是實際評測結果；學生端回報與伺服器評測分開。

**產生 Word 報告**：DeepSeek V4 Pro 直接撰寫完整教學報告，完成後自動下載可編輯的 .docx。內容包括學習概況、主要發現、適合所選年級的教學建議及後續跟進；有資料支持時附學生跟進參考。毋須輸入問題、另按分析、選模板或填寫教案表格。

同樣的資料再次下載會取回已保存的報告；有新的學習紀錄或範圍改變時會重新整理。生成期間請留在頁面；若停止等候，稍後按同一按鈕即可重試。切換範圍或登出會停止目前頁面的下載。

如果所選範圍尚無學習紀錄，Excel 仍可下載名冊；Word 會提示資料不足，不會編造學生表現。日期最多選 31 天。檔名包含班別及日期，方便保存。

報告和 Excel 只供已登入的教師下載。報告根據當時資料撰寫，教學建議供結合課堂觀察採用；未見紀錄不等於沒有學習，分數變化亦不能單憑本報告當作教學成效證明。

## 試用模擬後台

教師登入後，可在首頁按「體驗模擬後台」，或開啟 https://mandarin.aiducation.asia/maanshan/teacher-demo.html 。這裏有 775 名虛構學生、31 個班及過去 30 天的模擬學習紀錄，可選年級、班別，查看圖表、學生詳情，並使用相同兩個按鈕下載 Excel 或由 V4 Pro 撰寫的 Word 報告。

模擬頁面、下載檔名和檔案內容都標有「模擬數據」。模擬資料不會匯入真實學生紀錄或研究資料庫，生成的模擬報告亦與正式報告分開保存。按「返回正式後台」即可查看學校的真實資料。

## 伺服器保存

學校網頁保留原網址。帳戶、學習紀錄及新產生的正式／模擬報告由廣州 PostgreSQL 保存；Vercel 僅透過固定目的地的加密 SSH 通道轉送 API，不再依賴免費 Blob 額度。正式報告與模擬報告以獨立資料鍵分開；資料庫每日完整備份。

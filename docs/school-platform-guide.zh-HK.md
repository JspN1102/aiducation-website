# 學校帳戶、教師工作台及研究紀錄

本輪適用於 mandarin.aiducation.asia 學校平台。公司官網與原有示範頁維持原來的部署。

## 帳戶安排

- 按學校 Excel 的實際學生列建立 787 個學生帳戶，涵蓋 31 班，以及 9 個獨立教師帳戶。
- 原表的 763 人摘要漏計 4F 的 24 人；匯入以實際學生列為準，不把摘要列當成學生。
- 保留 786 個原學生密碼。原表一個空白學生密碼及九個教師初始密碼另外產生，清楚標示來源，原 Excel 未修改。
- 教師各自登入，均可查看六個年級、所有班別及學生，亦可重設學生密碼。每次重設留有不含密碼的操作紀錄；重設後學生原登入狀態會失效。
- 學生只可儲存與讀取自己的進度。共用裝置換號時，舊分頁會鎖定；離線記錄按帳戶分開，不能交給另一個學生。
- 帳戶及密碼交付檔只保存在桌面的受限私密資料夾，不放入網站、程式碼或研究匯出檔。

## 教師使用方法

登入學生平台時，教師帳戶會自動進入「教學觀察室」。亦可直接開啟 /maanshan/teacher.html。

1. 在「學習總覽」選年級、班別、日期及活動，再按「套用範圍」。
2. 查看參與、完成、各類測量及每日學習紀錄。未有有效分數顯示「未測」，實際零分顯示 0。
3. 在「學生紀錄」搜尋學生並開啟詳情，查看首次與最近一次的表現、活動紀錄和提示使用情況。
4. 朗讀、聽辨、默寫等分開顯示，不將選擇題的 0/100 與朗讀分數混成能力總分。重做及自由練習亦分開。
5. 在「資料品質與匯出」查看同步情況、缺失和技術失敗，並匯出去標識 JSONL/CSV、資料字典及校驗資料。匯出以研究代碼識別學生；因學校仍保存對照名冊，這是化名資料，並非不可逆的匿名資料。

本輪新增快捷日期、待套用條件提示，以及按「期內未有紀錄」「可再給予支持」等狀態查看學生。低分按朗讀、聽寫、字音等分項及資料來源標明，不混成總分。學生詳情可切換前後學生；匯出顯示已讀頁數與條數，可取消後重新匯出。

「期內未有紀錄」只表示所選期間沒有已收到的事件；資料追趕、待修復、名冊不可用時不推定學生未開始。同步異常在資料頁顯示待修復物件數及最後檢查時間，已到達的健康資料仍可查看。

日期範圍按 UTC 劃分，時間以香港時間顯示，頁面已標明。單次網頁查詢最多 31 天及 100,000 個事件；超過時須縮小年級、班別或日期。長期歷史仍保留在廣州 PostgreSQL，可由私密管理員導出工具讀取，不會因畫面查詢上限而截斷或刪除。

## 本輪紀錄範圍

| 活動 | 記錄內容 | 解讀界線 |
|---|---|---|
| 進入與切換 | 會話、活動、詩篇、時間、可見且近期有操作的累計時間 | 閒置或背景分頁時間不當作持續學習；缺事件時只估算可確認部分 |
| 示範與字音 | 實際開始／結束播放、播放時長與速率、目標詩句／字／題目、拼音提示 | 點擊與實際聽到分開，播放不代表理解 |
| 朗讀評測 | 每次錄音嘗試、停止、重試、技術錯誤、供應商回傳的綜合／準確／流利／完整度分數、可核對的逐字分數 | 缺分不填零；供應商分數是自動測量，需另做效度驗證 |
| 動畫 | 真正播放的片段時長、暫停、跳轉位置、自然結束、載入錯誤 | 跳到結尾不等於完整觀看，兩者可由時長與跳轉分辨 |
| 探索與六個遊戲 | 每步呈現、選擇、錯選、重試、提示、完成、相機操作結束 | 保留遊戲過程，不把遊戲完成算作測驗得分 |
| 聽辨與配對等 | 題目 ID、版本、題序、選項順序、選項／配對、首次及重做、作答時間 | 伺服器依題庫核對答案；不同構念分開分析 |
| 默寫與筆順 | 落筆筆數、撤銷／清空次數、筆順示範、辨認嘗試、首候選是否符合目標 | 不新增保存原始筆跡座標；看完答案的自由練習不覆蓋原作答 |
| 詩人聊天／報告 | 發起、回應、失敗、延遲、文字長度、提示使用及供應商版本 | 不新增保存聊天全文；報告生成不構成一次新的評分 |

事件包含版本、隨機研究代碼、事件／會話／嘗試 ID、年級班別及資料來源，供後續核對。正式測量與學生端觀察分開；原始歷史保留，教師頁面只是其可重建的統計視圖。

## 儲存及品質

廣州 PostgreSQL 保存正式追加歷史；日常備份包含帳戶及研究資料。備案期間，現有 Vercel 入口先寫入私密暫存，再由廣州定時向外讀取並發布私密教師統計。教師頁面顯示同步時間或追趕狀態；學生尚未上傳的離線記錄不能被伺服器看見。

事件只有在伺服器確認已持久化後，瀏覽器才移出待傳佇列。重複傳送依事件識別碼去重；共用帳戶的多個分頁不會互相覆寫研究佇列。儲存空間耗盡、裝置清除資料或瀏覽器禁用儲存仍可能造成未上傳資料缺失，不能聲稱零遺失。

離散測驗答案另設帳戶專屬補傳佇列，保留原請求識別碼與作答時間；只有服務端確認研究紀錄已持久化才移除。重新整理或斷網後可繼續補傳，不重新呼叫錄音評測或筆跡辨認服務。同一答案重傳不新增一次評分；相同識別碼卻有不同答案時保留衝突，不能覆寫原紀錄。

學生的「我的學習檔案」顯示待同步狀態與「再試同步」。裝置儲存失敗時提醒保留頁面；格式損壞或被服務端拒絕的本機紀錄保留並單獨標記，其他正常紀錄繼續上傳。此狀態表示本裝置上傳情況，不等同教師統計已即時更新。

同步器對損壞的伺服器暫存物件保存受限的待修復引用與原因代碼，分批重試；原始物件保留。已完整上傳的快照片段有檢查點，工作中斷後續傳。大量歷史的統計仍受頁面及快照容量限制；研究原始歷史以 PostgreSQL 與私密備份為準。

研究匯出使用研究代碼，不包含姓名、登入名稱、密碼或 IP。學校名冊與研究匯出分開管理。目前新增的保存範圍不含原始錄音、原始筆跡、聊天全文或裝置指紋；須依已獲批倫理文件確認額外範圍、保留期、退出／刪除程序及資料存取人員後，再另行實作相關流程。

## 用於研究之前

埋點提供可追溯的過程資料，不能替代研究設計或保證期刊接收。正式研究仍須固定研究問題、主要結果、前後測與課程安排、教師／班級差異、缺失處理及分析計畫。自選練習量與分數的關聯不能直接解釋為因果效果；不同年級的題目不同，不能單憑跨年級均分比較能力。

本輪驗證用合成帳戶、模擬評分及隔離 PostgreSQL；測試學習紀錄不混入正式學生歷史。後續課程內容更改須保留題庫版本和程式提交，才能解讀舊事件。

研究問題、指標選擇及分析準備可參考同目錄的 `research-use-plan.zh-HK.md`；完整欄位定義以 `research-data-dictionary.json` 為準。

《中华经典文化村 · 村口春景》v6.0 精修版
=====================================

一款等距工笔画风的古诗文化体验网页小游戏（面向小学生）。
三首春诗（春晓 / 咏鹅 / 绝句）+ 三个诗意小游戏 + 村口春景卷。

怎么开始
--------
双击 index.html（用 Chrome / Edge / 最新浏览器打开即可，无需联网、无需安装）。
点「走进文化村」开始；已有进度时点「继续游历」。

操作
--------
· 键盘 WASD / 方向键走动，或鼠标（手指）点地面自动寻路
· 靠近人物或发光的事物，按 E（或点屏幕上的提示）互动
· 右上角小卷轴查看「村口春景卷」进度；H 看帮助；Esc 关闭窗口
· 进度自动保存在本机浏览器，下次点「继续游历」接着玩
